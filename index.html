Install in three steps

Launcher

  1. Download the installer.
  2. Run vexora-launcher-setup.exe.
  3. Open Vexora and press Play.

Portable

  1. Download vexora-portable.zip.
  2. Extract it to any folder.
  3. Start the launcher inside.

Mod (.jar)

  1. Download vexora.jar.
  2. Open the mods folder of your instance in Prism Launcher, Modrinth App, CurseForge or the Minecraft Launcher.
  3. Drop vexora.jar in and start the game.
